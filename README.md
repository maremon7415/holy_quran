# Noor Quran — نُورُ القُرْآن

A fast, beautiful, SEO-first Quran web app: read, listen, understand and memorise the Holy Quran in Arabic, Bangla and English. Free, ad-free, open source.

## Highlights
- **Reader** – Uthmani text, Saheeh International / Abdel Haleem English, Taisirul Quran Bangla, transliteration, tajweed colours, word-by-word (tap a word to hear it), Mushaf flow mode, 4 Quran fonts, 5 themes (Pearl, Parchment, Dusk, Midnight, Pure Black), focus mode, keyboard shortcuts, deep links (`#ayah-N`).
- **Audio** – 28 reciters, chapter audio with **word-by-word highlighting** synced to the recitation, repeat ayah, range loop, speed, sleep timer, lock-screen controls, `/listen`.
- **Tafsir** – Ibn Kathir (EN), Ahsanul Bayaan (BN), Tafsir Muyassar (AR).
- **Hifz Studio** – listen → read → fade → recall steps, SM-2 spaced repetition, optional voice recitation check.
- **My Journey** – streaks, daily goal, 365-day heatmap, achievements, Khatam planner over the 604 mushaf pages.
- **Knowledge** – 40 Quran topics ("What does the Quran say about…", incl. feelings), 80 authentic duas with sources, 99 Names of Allah with quiz & flashcards.
- **Daily life** – prayer times, Qibla compass, Hijri calendar, tasbih counter, masayel.
- **Search** – ⌘K command palette: surah names (EN/BN/AR), `2:255` references and full-text search across Arabic, English and Bangla.
- **Share as image** – beautiful 1080×1350 ayah cards.
- **SEO / AI visibility** – every surah, juz, topic, dua and name is pre-rendered; 6,236 single-ayah landing pages; JSON-LD (Book/Chapter, Quotation, FAQPage, BreadcrumbList, Article); sitemaps; `robots.txt` welcoming AI crawlers; `/llms.txt` and `/llms-full.txt`; dynamic OG images.
- **PWA** – installable, offline reading via service worker, custom illustrated PNG icon set.

## Develop
```bash
pnpm install
pnpm dev            # http://localhost:3000
pnpm build && pnpm start
```
Set `NEXT_PUBLIC_SITE_URL` to your production URL (used for canonical URLs, sitemaps and OG). Accounts (`/login`) are optional and need `MONGODB_URI` + `AUTH_SECRET`; everything else works without a database (user data stays on the device, with JSON backup/restore in Settings).

## Data
- `data/quran/` – the full corpus, generated by `node scripts/fetch-quran-data.mjs` from the open [Quran.com / Quran Foundation API](https://api-docs.quran.com).
- Runtime: word-by-word, tajweed, tafsir (api.quran.com), audio + word timings (api.qurancdn.com), per-ayah audio fallback (everyayah.com).
- `data/content/` – topics, duas, 99 names. Validate with `node --experimental-strip-types scripts/validate-content.mjs` (checks every Quran reference exists).
- Icons: `node scripts/icons/render.mjs` re-renders the PNG icon set from SVG sources.
